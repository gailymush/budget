# 記帳存摺

一個可以加到 iPhone 主畫面、連接到你自己 Google 試算表的記帳網頁 App（PWA）。
不需要 Xcode、不需要上架 App Store，設定好之後就能像原生 App 一樣使用。

整體架構很單純：
- **前端**：`index.html`（連同 `manifest.json`、`sw.js`、`icons/`）— 你手機上看到、操作的畫面。
- **後端**：一段貼到 Google 試算表裡的 Apps Script 程式（`Code.gs`）— 負責把資料寫進 / 讀出你的 Google 試算表，完全免費、不需要另外租伺服器。

---

## 第一步：建立 Google 試算表 + 後端

1. 到 [sheets.google.com](https://sheets.google.com) 建立一個**空白**新試算表，取名例如「記帳存摺資料」。
2. 上方選單「**擴充功能**」→「**Apps Script**」，會開啟一個新分頁。
3. 把 `Code.gs` 的完整內容複製貼上，取代編輯器裡原本的 `function myFunction() {}`，按左上角磁片圖示存檔。
4. 右上角「**部署**」→「**新增部署作業**」：
   - 類型選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**任何人**
   - 按「**部署**」
5. 第一次部署會跳出授權畫面：選你的 Google 帳號 → 如果出現「Google 尚未驗證這個應用程式」的警告，屬正常現象（因為這是你自己的程式），點「**進階**」→「**前往「記帳存摺」（不安全）**」→ 允許。
6. 部署完成後，會給你一組「**網頁應用程式網址**」，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   複製這個網址，等一下會貼到 App 的設定裡。

   之後你在 Apps Script 裡如果又修改了程式碼，記得要「部署」→「管理部署作業」→ 選現有部署 → 版本選「新版本」→ 部署，網址才會套用新程式碼。

不需要手動建立欄位，第一次寫入資料時，程式會自動在試算表裡建立一個叫「記帳明細」的工作表，欄位為：建立時間、日期、收支、類別、項目、金額、備註、ID。

---

## 第二步：把 App 放到網路上（才能安裝到 iPhone）

iOS 要求 PWA 必須透過 **https** 網址才能正常安裝、離線使用，不能只是本機的 `index.html` 檔案。最簡單、完全免費的方式是用 **GitHub Pages**：

1. 到 [github.com](https://github.com) 註冊帳號（如果還沒有）。
2. 新增一個 repository（例如叫 `my-ledger`），設為 Public。
3. 把這個資料夾裡的所有檔案（`index.html`、`manifest.json`、`sw.js`、`icons/`、`Code.gs`、`README.md`）上傳上去（網頁介面右上角「Add file」→「Upload files」，把檔案拖進去即可）。
4. Repository 的「Settings」→「Pages」→ Source 選「Deploy from a branch」，Branch 選「main」／資料夾「/ (root)」，儲存。
5. 等 1-2 分鐘，頁面會顯示一個網址，通常是：
   ```
   https://你的帳號.github.io/my-ledger/
   ```
   這就是你之後在 iPhone 上開啟的網址。

（如果你比較熟悉 Netlify、Cloudflare Pages 等其他免費靜態網站服務，直接把整個資料夾拖上去部署也可以，效果一樣。）

---

## 第三步：設定 App 並加到主畫面

1. 用 **iPhone 的 Safari**（一定要用 Safari，不能用 Chrome）打開你剛剛的網址。
2. 畫面最下面「設定」欄位，貼上第一步拿到的 Apps Script 網址，按「儲存」。
3. 看到「已連線，資料同步自你的 Google 試算表」代表成功了，可以開始記帳。
4. 點 Safari 下方的「分享」按鈕 → 「加入主畫面」，App 圖示就會出現在 iPhone 桌面上，之後直接點圖示打開，畫面會是全螢幕、沒有網址列，跟一般 App 一樣。

---

## 使用方式

- 上方選「支出」或「收入」，選類別、輸入項目與金額，按「記一筆」就會即時寫進你的 Google 試算表。
- 首頁會顯示當月結餘、收入、支出，並可用月份選單切換查看之前的月份。
- 若當下沒有網路，記錄會先暫存在手機裡（標示「同步中」），恢復網路連線後會自動補送。
- 所有資料都存在**你自己的 Google 試算表**裡，你可以隨時打開試算表用公式、樞紐分析表做更進一步的統計。

## 之後可以自己調整的地方

- 類別清單在 `index.html` 裡的 `CATS` 這個物件，可以自行增減。
- 顏色、字體等視覺樣式都在 `index.html` 的 `<style>` 區塊裡。
